What to fix in Figma first

Full list in the audit; these are the ones that change what the design and the code can follow.

1 Deleted type scale still bound

About 2,040 text nodes use typescale/impact/*, which no longer exists. Only 218 use the live Default/* scale. The code follows the deleted one.

2 Settings drive nothing

Radius, shadow, texture, motion and spacing are plain strings. Components bind radius/rounded/sm (316) and shadow/strong/md directly, so a theme’s radius and shadow never change in Figma.

3 Principles can’t vary

All four alias the left-hand answer in every mode, so no theme can choose the right. Six questions exist; four principles map to them by different names.

4 Scopes and code syntax

160 of 270 variables are ALL_SCOPES; none has code syntax; 154 have no description. Dev Mode can’t show the CSS name.

5 Newest collections unused

spacing, icons and size-controls (41) have no bindings. The file uses remote Size/Space/* and Size/Stroke/Border instead.

6 Font and colour tidy-up

Body is named font not family; Display and Heading duplicate; some primitives repeat (Berghain 300 and 400, Bootshaus 400 and 500); Fabrik is “light” with a dark background.

Counts are direct node bindings on the Home, Themer and Audit pages; variables used through text or effect styles, or in prototypes, are not counted. Source: Figma Themes file RUommmb1rQZk7X7TxbFPCC.
